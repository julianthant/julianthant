## Hi, I'm Julian

I'm a CS student at UC San Diego. I like building things that handle the boring, repetitive parts of someone's job. Lately that's meant browser automation, AI agents, and a bit of quant research on the side.

## What I'm building

- **[HR-Relay](https://github.com/julianthant/hr-relay)**: I work in an HR office, where onboardings, separations and employee lookups meant clicking through a pile of university systems by hand. HR-Relay logs in and does the clicking for you. If it isn't sure a submission went through, it stops and asks a person.
- **[Tether](https://github.com/julianthant/tether)**: a way to let a coding agent work on its own for hours without giving it the whole machine. It can only touch files in one folder, and it saves its progress, so a killed run picks up where it left off.
- **[Driftwood](https://github.com/julianthant/driftwood)**: a small research pipeline for US stocks. The plan is to train simple models on daily data and only test them on periods they've never seen. Then a C++ simulator shows how much fees and slippage eat into the results.
